# Render Site

Статический сайт с Node.js сервером и автоматической перезагрузкой при изменении файлов.

## Установка

1. Установите зависимости:
```bash
npm install
```

## Запуск

Запустите сервер разработки:
```bash
npm start
```

или

```bash
npm run dev
```

Сервер запустится на `http://localhost:3000`

## Возможности

✅ **Live Reload** - страница автоматически перезагружается при изменении:
- HTML файлов
- CSS файлов
- JavaScript файлов
- Изображений
- Шрифтов

✅ **Простой запуск** - один файл сервера без сложной конфигурации

✅ **Консольные уведомления** - видите все изменения файлов в реальном времени

## Редактирование

Просто редактируйте любые файлы в папке проекта, и изменения автоматически отобразятся в браузере!

## Остановка сервера

Нажмите `Ctrl+C` в терминале для остановки сервера.
